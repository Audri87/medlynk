# Decision Records — Index

Les Decision Records documentent le raisonnement derrière les choix méthodologiques du CWRM.

Ils ne définissent pas les règles. Ils expliquent pourquoi ces règles ont été choisies plutôt qu'une alternative.

Un Decision Record peut être consulté sans lire la spécification correspondante.
